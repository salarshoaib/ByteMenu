## What it is
A JavaFX desktop application that lets university students browse the cafeteria menu, customize and place orders, pay online, reserve a seat, and track their order in real time. A separate Admin/Chef Portal lets kitchen staff manage order statuses with full authority.

## How to run
1. Open in IntelliJ IDEA
2. Make sure JDK 21 and JavaFX 21 are configured
3. Run `MainApp.java`
4. The SQLite database (`bytemenu.db`) is created automatically on first run

## Login credentials
- **Students:** Register a new account on the Login screen
- **Admin/Chef:** Username `Admin`, Key `1234`
